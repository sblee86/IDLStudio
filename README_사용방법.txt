IDL Studio · 오프라인 버전 0.25

실행
ZIP을 모두 압축 해제하고 IDL-Studio.html을 Chrome/Edge로 엽니다.
폴더 선택이 브라우저 정책으로 제한되면 폴더 가져오기(읽기) 또는 IDL 가져오기를 사용하세요.
설치, 로그인, 인터넷 연결 및 서버가 필요하지 않습니다.
사용자가 선택한 파일은 브라우저 안에서만 처리합니다.

이번 버전
- 7개 탭 도움말 및 About: GPT 제작, 최초 배포자 이상범, 자유 배포 안내
- 오픈소스 라이선스 원문과 별도 배포 안내 파일 포함
- 양식 이름/기본 양식/안내 접기, 템플릿 5개 영역 개별 접기 및 본문만/전체 펼치기
- 미리보기 숨김으로 작성 공간 확대, 접힘 상태 폴더 설정 저장
- 출력 포맷 관리창 드래그 이동/크기 조절, 위치/크기 폴더 설정 저장
- 상단 메뉴/치환자 도구 고정, 템플릿 영역만 독립 스크롤
- 템플릿 우클릭 치환자 검색/이스케이프/선택 영역 삽입
- 같은 열의 위/아래 칸 이동: 기본 Shift+방향키, 설정에서 재지정 가능
- 필드 순서 Alt+방향키와 구분, 비활성/검색 제외 칸 건너뛰기 및 이전 설정 호환
- 문서 탭, 구조체 이름/도구/표 머리글, Markdown 제목/안내/표 머리글 높이와 글씨 독립 설정
- 내부 제목줄 휠 높이 및 Ctrl+휠 글씨 조절, 경계 드래그, 폴더 설정 자동 저장
- 제목줄/메뉴줄/도구줄 높이 휠·경계 드래그 조절 및 공간·확대 설정 탭
- 구조체/Markdown Ctrl+휠 배율, 스크롤바 두께 및 레이아웃 폴더 설정 저장
- 중복 본문 구조체명 줄 제거, 필드 수와 크기는 문서 탭 우측에 표시
- 설정창 상단 드래그 이동 및 오른쪽 아래 크기 조절, 비모달 본문 확인
- Markdown 뷰어 글자/색상/다이어그램 설정 및 앱 내 문법 작성 안내
- NOM:interaction 등 임의 접두사 태그 허용. 네임스페이스 미선언은 경고로 원문 출력 허용
- 닫는 태그 불일치/따옴표 등 실제 XML 문법 오류는 차단하고 원인 표시
- XML 오류가 나도 생성된 텍스트는 미리보기에 유지
- examples/NOM-Interaction-Demo.idl.json: NOM:interaction 원문/네임스페이스 선언 양식 포함. IDL 가져오기로 확인 가능
- 출력 양식 추가/복제 즉시 왼쪽 목록에 생성하고 선택
- 복제 이름은 이름(1), 이름(2) 순서. 목록 우클릭 복제/삭제
- 양식별 편집 초안을 유지하여 목록 전환 시 입력 손실 방지. 양식 저장으로 반영
- 우상단 전체 저장 추가: 모든 IDL/MD/설정 파일을 연결된 작업 폴더에 저장
- 파일의 모두 저장과 지정한 단축키도 동일한 통합 저장 경로 사용
- 작업 폴더 열기 시 IDL/문서 목록/MD 본문/설정을 함께 읽는 기존 흐름 확인
- 저장 실패/부분 완료를 구분하고 모든 파일 저장 후에만 전체 저장 완료 표시
- IDL별 여러 Markdown 문서 지원. IDL 우클릭 → MD 파일 추가
- MD 우클릭: 열기/보기, 편집, 이름 변경, 삭제 및 추가
- 추가 문서는 IDL이름.docs/문서이름.md, 기존 IDL이름.md는 유지
- 저장/모두 저장/폴더 ZIP/브라우저 복구에 전체 문서 포함
- Markdown 이름 변경/삭제는 연결된 실제 파일에 반영. 삭제는 복구 불가
- IDL마다 동일 폴더의 IDL이름.md 문서 생성/읽기/편집/보기/나란히 보기
- Mermaid Sequence / State Machine / Activity(flowchart) 예제 삽입과 다이어그램 미리보기
- 문서 저장 및 IDL 모두 저장에 Markdown 포함. ZIP에도 Markdown 포함
- HTML/스크립트는 미리보기에서 제거하며 외부 이미지 요청은 하지 않음
- 다이어그램 라이브러리를 포함하여 오프라인 동작
- 시작 화면에서 이전 작업 폴더로 연결 / 새 폴더 지정 선택
- 이전 폴더는 저장된 핸들로 권한을 확인하여 폴더 선택창 없이 다시 연결
- 우상단 작업 폴더 미리보기로 버튼명 변경, 미리보기의 웹 제한 설명 삭제
- 우상단 작업 폴더 열기는 연결된 폴더 파일 목록/미리보기. 폴더 변경은 설정에서
- 일반 웹에서는 Windows 탐색기를 직접 실행할 수 없습니다
- 폴더 ZIP을 작업 폴더 안에 저장. 미연결 시 저장하지 않고 안내
- 설정을 화면/작업폴더/단축키/삭제확인 탭으로 분리
- 본문 구조체 제목 크기 설정(12~48px), 불필요한 제목/설명 줄 제거
- 탐색기 상단 선택 삭제 아이콘과 IDL/구조체 우클릭 추가/삭제 메뉴
- 선택 강조와 삭제 대상 툴팁. Shift+F10/메뉴 방향키/Esc 지원
- IDL Studio로 이름 변경. 우상단 작업 폴더 열기와 도움말 추가
- 삭제 확인의 다시 묻지 않음을 종류별로 보관. 설정에서 확인창 다시 켜기 가능
- 삭제 확인 설정을 작업 폴더 설정 파일에 저장
- 시작 화면에서 작업 폴더 선택. 복구 작업은 별도 선택으로 폴더 연결
- 작업 폴더/설정 위치를 탐색기 하단과 설정 화면에 표시
- 화면/단축키 설정을 작업 폴더의 ICD-Studio.settings.json에 자동 저장하고 폴더 열 때 읽음
- IDL 파일 저장은 Ctrl+S/모두 저장, 브라우저 자동 복구와 구분
- 브라우저는 전체 OS 경로를 제공하지 않으므로 폴더명과 상대 경로 표시
- 설정에서 단축키 직접 입력/변경/해제/기본값 복원 및 자동 저장
- IDL/구조체/필드 삭제 단축키 추가. 삭제 확인과 참조 검사는 유지
- ICD 수정 메뉴: IDL 추가/삭제, 구조체/필드 관리
- 단축키: Ctrl+Alt+F 필드 추가 / Ctrl+Alt+S 구조체 즉시 추가 / Ctrl+Alt+N IDL 추가 / Alt+위아래 필드 순서 이동
- 가져오기 메뉴: H/CSV 분석과 미리보기 후 현재 IDL에 구조체 추가
- H: 고정 배열, std 정수형, 기본형, 구조체 참조. 포인터/비트필드/매크로/namespace/typedef 별칭은 미지원
- CSV: 필드명(name), 자료형(type) 필수. 개수/count, 최소/min, 최대/max, 단위/unit, 설명/description, 구조체명/structure 선택
- 이름 충돌/지원하지 않는 선언/잘못된 범위는 가져오기 전 차단
- IDL 삭제는 확인 후 연결된 실제 파일도 삭제합니다. 복구 불가. 미연결 원본은 유지합니다.
- HTML의 폴더 자동 접근은 브라우저 보안상 불가합니다. 처음 한 번 작업 폴더를 선택하세요.
- 폴더 열기는 최근 폴더를 기억합니다. 폴더가 미연결일 때 저장하면 폴더를 선택해 연결합니다. 기존 동명 파일은 덮어쓰지 않습니다.
- 폴더 → 장비별 IDL → 구조체 탐색기로 변경
- 폴더 열기 / 새 장비 IDL / 현재 IDL 저장 / 모두 저장 / 폴더 ZIP
- 우측 고정 정보패널 제거, 우상단 검증 팝오버(마우스 올리기/클릭)
- 설정 메뉴: 전체 기준 글씨 10~22px, 메뉴/아이콘 70~120%, 행 높이 28~72px
- 글씨·메뉴·행높이·테마는 즉시 반영하고 브라우저에 자동 저장

기존 기능
- 출력 포맷 관리 메뉴: XML/JSON/C++ 헤더(.h) 양식 추가·복제·편집·삭제
- 머릿글/상부 선언부/본문 반복/하부 선언부/맺음말의 5개 영역 구성
- 치환자 삽입, 기본 영역 선택, 실시간 미리보기와 다운로드
- 출력 양식은 IDL JSON에 함께 출력 포맷 사용
- 상단 출력 포맷 메뉴에서 XML/JSON/H 양식을 선택합니다.
- 머릿글과 맺음말은 파일당 한 번, 상부/하부는 구조체마다 한 번, 본문은 필드마다 반복합니다.
- 각 템플릿은 문자 그대로 이어 붙입니다. 필요한 줄바꿈도 템플릿에 넣어주세요.
- 예: {{field.cppType}} {{field.name}}{{field.array}};
- 최소/최대/설명: {{field.min|comment}}, {{field.max|comment}}, {{field.description|comment}}
- JSON 문자열은 |json(따옴표 포함), XML 속성은 |xml, 한 줄 주석은 |comment를 사용합니다.
- JSON의 마지막 쉼표는 {{field.comma}}, {{struct.comma}}로 처리합니다.
- 양식 저장 후 IDL 저장을 누르면 양식 설정도 JSON에 보관됩니다.
- 파일 내보내기는 현재 초안을 사용합니다. 저장하지 않은 초안은 프로젝트에 포함되지 않습니다.
- 출력 파일 XML/JSON은 정의서이며 재편집용 IDL JSON과 형식이 다릅니다.
- H 파일에는 참조하는 구조체를 의존 순서로 포함합니다.
- XML/JSON 문법 오류 및 잘못된 치환자가 있으면 내보내기를 막습니다.
- 기본 H 양식의 C++17 구문을 검사했습니다. 사용자 양식은 실제 컴파일러에서 확인하세요.

저장

이전 버전의 기능
1. 왼쪽/오른쪽 패널 경계와 리본 아래 경계를 드래그하여 크기 조절
2. 표 제목 열 사이의 경계를 드래그하여 열 너비 조절
3. 경계 더블클릭으로 해당 크기 복원, 보기 메뉴의 배치 초기화로 전체 복원
4. 자료형 메뉴: 사용자 자료형 / 구조체·헤더 / 기본형 카탈로그
5. int32 등 기본형을 바탕으로 별칭 자료형 추가·수정·삭제
6. 구조체를 자료형 목록에 등록하고 헤더 구조체로 지정
7. 다른 구조체의 필드 자료형에서 등록된 헤더/구조체 선택
8. 포함된 구조체·배열의 크기 및 Offset 재귀 계산
9. 순환 참조 차단, 사용 중인 타입/구조체 삭제 차단
10. v0.1 IDL JSON 불러오기 지원

헤더 사용 방법
- 자료형 메뉴 → 구조체 / 헤더 탭 → 기존 구조체의 헤더 지정 체크
  또는 '새 헤더 구조체' 버튼으로 추가하고 본문에서 필드를 작성합니다.
- 대상 구조체로 이동 → 필드 추가 → 자료형 목록의 '헤더 구조체'에서 선택합니다.
- 일반 구조체도 '자료형 등록'을 체크하면 필드에서 사용할 수 있습니다.
- 자기 자신 및 간접 순환 참조를 만드는 후보는 자료형 목록에서 제외됩니다.
- 헤더의 이름과 필드가 바뀌어도 ID 참조를 유지하며 크기를 다시 계산합니다.

사용자 자료형
- 기본형 int32의 크기/표현 범위 자체는 고정입니다.
- 예: Temperature / int32 / 최소 -40 / 최대 125로 별칭을 정의합니다.
- 사용자 타입의 기본형을 수정하면 사용 중인 필드의 크기/검증도 갱신됩니다.
- 수치 범위는 문자열로 보관하여 int64/uint64 정밀도를 유지합니다.

폴더와 IDL 저장
- 폴더 안의 각 장비 IDL은 CFCS_IDL.idl.json, MIU_IDL.idl.json처럼 별도 파일로 보관합니다.
- sample-folder에 예제 작업 폴더를 넣었습니다. 폴더 열기로 선택해 볼 수 있습니다.
- 폴더 열기는 .idl.json 및 이전 .icd.json을 읽습니다. XML/OMG IDL 원문은 읽지 않습니다. H와 CSV는 가져오기 메뉴를 사용합니다.
- Chrome/Edge가 File System Access API를 허용하면 폴더 읽기/쓰기를 연결합니다.
- 쓰기 지원이 없으면 폴더 파일을 읽기 모드로 가져오며 IDL/ZIP 다운로드로 보관합니다.
- 새 IDL은 먼저 화면에 추가되며 IDL 저장 또는 모두 저장 시 실제 파일을 만듭니다.
- 외부에서 변경된 파일 또는 새 IDL과 이름이 충돌하는 파일은 덮어쓰지 않습니다.
- IDL별 타입/헤더/출력 양식과 실행 취소 상태를 분리합니다. IDL 간 구조체 참조는 지원하지 않습니다.
- 브라우저 재실행 시 내용은 복구하지만 디스크 핸들은 자동 연결하지 않습니다. 폴더를 다시 선택하세요.
- 자동 복구와 디스크 저장은 다릅니다. 별도로 파일을 저장해 보관하세요.
- 화면 설정은 이 브라우저/실행 파일 위치에 저장됩니다. 위치 변경이나 브라우저 데이터 삭제 시 초기화될 수 있습니다.

IDL 편집
- Enter 또는 셀 밖 클릭으로 입력을 확정합니다.
- IDL 저장으로 JSON 파일을 다운로드합니다. HTML을 덮어쓰지 않습니다.
- JSON에는 사용자 자료형, 구조체, 헤더 지정 및 필드 참조가 함께 저장됩니다.
- 패널/열 너비는 브라우저에 별도로 저장되며 IDL JSON에는 포함되지 않습니다.
- file:// 환경의 자동 복구 저장은 브라우저 정책과 파일 위치에 따라 달라질 수 있습니다.
  JSON 파일을 작업 보관의 기준으로 사용하세요.
- 이전 v0.1 JSON을 불러온 경우 원하는 구조체를 직접 헤더/타입으로 등록하세요.
- CSV는 현재 구조체의 필드 정의 표 출력입니다. 재편집은 JSON을 사용합니다.

제한
Offset은 패딩 없는 연속 배치입니다. C/C++ ABI 정렬을 계산하지 않습니다.
XLSX, 비트 필드, 가변 길이 배열은 아직 지원하지 않습니다.
기본형을 직접 변조하는 대신 사용자 자료형으로 의미/범위를 확장합니다.
0.1/0.2 IDL 파일을 읽을 수 있습니다. 0.3 이전 앱은 출력 포맷 설정을 유지하지 못할 수 있습니다.
소스는 source 폴더에 포함되어 있으며 브라우저에서도 확인할 수 있습니다.

검증
웹 브라우저에서 헤더 선택, 크기 전파, 사용자 타입, 범위 오류 및 경계 드래그를 확인했습니다.
자료형/JSON/배열/순환 참조 관련 자동 검사를 수행했습니다.
실행용 HTML 외부 의존성 제거와 JavaScript 문법 검사를 수행했습니다.
Windows의 file:// 직접 실행 및 실제 OS 폴더 선택/쓰기 권한 UI는 이 제작 환경에서 검증하지 못했습니다.
폴더 저장/이름 충돌/외부 변경 차단 로직은 가상 파일 핸들로 검사했습니다.
